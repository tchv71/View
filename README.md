# File viewer
Both for CP/M and rk86 shell by Alex Morozov
## Кеуs
|**Key**|**Action**|
|---------|---------|
| **4**|view HEX|
| **Up**| up a line|
|**Down**|down a line|
|**Ctrl+Up**|up a page
|**Ctrl+Down**|down a page
|**Shift+Up**|to beginning of a file
|**Shift+Down**|to end of a file
|**Esc,^C**|exit to shell
